# getFont()

Return the label's [Font](../font/index.md).

## Parameters

Once an object `label` has been created, you can use the following function:

```python
label.getFont()
```

## Returns

`return font`

| Value | Type | Description |
|---|---|---|
| font | `Font` | The font of the label's text.  If no font was given, this is the default font (Arial, size 13). |
