# getFont()

Return the field's [Font](../font/index.md).

## Parameters

Once an object `field` has been created, you can use the following function:

```python
field.getFont()
```

## Returns

`return font`

| Value | Type | Description |
|---|---|---|
| font | `Font` | The font of the field's text.  If no font was given, this is the default font (Arial, size 13). |
