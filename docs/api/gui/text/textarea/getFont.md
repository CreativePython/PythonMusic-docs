# getFont()

Return the area's [Font](../font/index.md).

## Parameters

Once an object `area` has been created, you can use the following function:

```python
area.getFont()
```

## Returns

`return font`

| Value | Type | Description |
|---|---|---|
| font | `Font` | The font of the area's text.  If no font was given, this is the default font (Arial, size 13). |
