# setTextColor()

Set the button's text [Color](../../color/index.md).

This changes only the color of the text.  To change the button's background color, use [setColor()](../../common/color/setColor.md).

## Parameters

Once an object `button` has been created, you can use the following functions:

```python
button.setTextColor()
```

```python
button.setTextColor(color)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `color` | `Color` | `None` | The new text color. If omitted, a color-selection dialog opens. |
