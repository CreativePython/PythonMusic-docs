# getFont()

Return the button's [Font](../../text/font/index.md).

## Parameters

Once an object `button` has been created, you can use the following function:

```python
button.getFont()
```

## Returns

`return font`

| Value | Type | Description |
|---|---|---|
| font | `Font` | The font of the button's text.  If no font was given, this is the default font (Arial, size 13). |
