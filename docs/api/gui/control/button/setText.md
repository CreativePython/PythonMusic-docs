# setText()

Set the button's text.

## Parameters

Once an object `button` has been created, you can use the following functions:

```python
button.setText(text)
```

```python
button.setText(text, resize)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `text` | `str` | _required_ | The new text to show on the button. |
| `resize` | `bool` | `True` | `True` to resize the button to fit the new text, or `False` to keep its current size. |
