# getFont()

Return the list's [Font](../../text/font/index.md).

## Parameters

Once an object `dropdown` has been created, you can use the following function:

```python
dropdown.getFont()
```

## Returns

`return font`

| Value | Type | Description |
|---|---|---|
| font | `Font` | The font of the list's text.  If no font was given, this is the default font (Arial, size 13). |
