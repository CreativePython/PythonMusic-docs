# getFont()

Return the checkbox's [Font](../../text/font/index.md).

## Parameters

Once an object `checkbox` has been created, you can use the following function:

```python
checkbox.getFont()
```

## Returns

`return font`

| Value | Type | Description |
|---|---|---|
| font | `Font` | The font of the checkbox's text.  If no font was given, this is the default font (Arial, size 13). |
