# setText()

Set the checkbox's text.

## Parameters

Once an object `checkbox` has been created, you can use the following functions:

```python
checkbox.setText(text)
```

```python
checkbox.setText(text, resize)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `text` | `str` | _required_ | The new text to show beside the checkbox. |
| `resize` | `bool` | `True` | `True` to resize the checkbox to fit the new text, or `False` to keep its current size. |
