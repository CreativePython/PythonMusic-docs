# getHeight()

Return the object's height.

This is the object's own height before rotation, so it stays the same as the object rotates.  For the height of the upright box around the rotated object, use [getBoundingHeight()](getBoundingHeight.md).

## Parameters

Once an object `item` has been created, you can use the following function:

```python
item.getHeight()
```

## Returns

`return height`

| Value | Type | Description |
|---|---|---|
| height | `int or float` | The height, in pixels. |
