# Duration Constants

Note durations are represented using real numbers (floats). For example, 4.0 stands for a whole note, 2.0 for a half note, 1.0 for a quarter note, and so on.

The music library defines the following constants for common duration values:

```python
DWN                        = 6.0
DOTTED_WHOLE_NOTE          = 6.0
WN                         = 4.0
WHOLE_NOTE                 = 4.0
DHN                        = 3.0
DOTTED_HALF_NOTE           = 3.0
DDHN                       = 3.5
DOUBLE_DOTTED_HALF_NOTE    = 3.5
HN                         = 2.0
HALF_NOTE                  = 2.0
HNT                        = 4.0 / 3.0
HALF_NOTE_TRIPLET          = 4.0 / 3.0
QN                         = 1.0
QUARTER_NOTE               = 1.0
QNT                        = 2.0 / 3.0
QUARTER_NOTE_TRIPLET       = 2.0 / 3.0
DQN                        = 1.5
DOTTED_QUARTER_NOTE        = 1.5
DDQN                       = 1.75
DOUBLE_DOTTED_QUARTER_NOTE = 1.75
EN                         = 0.5
EIGHTH_NOTE                = 0.5
DEN                        = 0.75
DOTTED_EIGHTH_NOTE         = 0.75
ENT                        = 1.0 / 3.0
EIGHTH_NOTE_TRIPLET        = 1.0 / 3.0
DDEN                       = 0.875
DOUBLE_DOTTED_EIGHTH_NOTE  = 0.875
SN                         = 0.25
SIXTEENTH_NOTE             = 0.25
DSN                        = 0.375
DOTTED_SIXTEENTH_NOTE      = 0.375
SNT                        = 1.0 / 6.0
SIXTEENTH_NOTE_TRIPLET     = 1.0 / 6.0
TN                         = 0.125
THIRTYSECOND_NOTE          = 0.125
TNT                        = 1.0 / 12.0
THIRTYSECOND_NOTE_TRIPLET  = 1.0 / 12.0
REST                       = -2147483648
```
